
# 📊 Expense Tracker App

A dynamic, user-friendly Expense Tracker mobile application built using **Flutter** and **Dart**. Designed to help users log daily spending, classify expenses by categories, and monitor their total expenditure in real time.

---

## 🌟 Key Features

* **Real-time Total Calculation:** Instantly calculates and updates total expenditure as new entries are added or deleted.
* **Category Tagging:** Assign categories (*Food, Travel, Bills, Entertainment*) with dynamic visual icons.
* **Modal Bottom Sheet Entry:** Clean pop-up form interface for entering new expenses without leaving the main dashboard.
* **Item Management:** Dismiss or delete individual expenses with automatic state re-indexing.

---

## 🛠️ Built With

* **Flutter** - UI Framework
* **Dart** - Programming Language
